# Changelog

All packages in this repository share one version and are released together.

## 0.1.0 (2026-08-17)

Initial release of `Altinn.AspNet.HealthChecks`, `Altinn.AspNet.HealthChecks.Warmup` and
`Altinn.AspNet.HealthChecks.OpenTelemetry`: the endpoint/tag convention extracted from
Dialogporten, a readiness-gating startup warmup building block, and an OpenTelemetry span
processor that keeps health probe traffic out of traces.

Published by manual workflow dispatch before release automation took over, so this entry is
written by hand — subsequent releases are generated by release-please from commit messages.
