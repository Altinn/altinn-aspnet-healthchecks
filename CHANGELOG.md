## [0.3.0](https://github.com/Altinn/altinn-aspnet-healthchecks/compare/v0.2.0...v0.3.0) (2026-08-21)


### ⚠ BREAKING CHANGES

* the response body is a new format under a new content type, application/vnd.altinn.health.v1+json. Statuses are lowercase; `exception` is an object with message/stackTrace/innerException rather than a string; `data`, `tags`, `description` and `exception` are omitted when absent or withheld, where `data` was previously always present. HealthChecks UI dashboards will no longer parse it.

## 0.1.0 (2026-08-17)

Initial release of `Altinn.AspNet.HealthChecks`, `Altinn.AspNet.HealthChecks.Warmup` and
`Altinn.AspNet.HealthChecks.OpenTelemetry`: the endpoint/tag convention extracted from
Dialogporten, a readiness-gating startup warmup building block, and an OpenTelemetry span
processor that keeps health probe traffic out of traces.

Published by manual workflow dispatch before release automation took over, so this entry is
written by hand — subsequent releases are generated by release-please from commit messages.
